# MET Landing Page is a responsive website for the MET museum with full functionality: navigation, gallery, feedback form, scrolling animation.

## Project overview

## Fully responsive layout for
- Desktop: 1260px+
- Desktop-small: 1020px - 1259px
- Tablet: 744px - 1019px
- Mobile: 320px - 743px

- [DEMO LINK](https://zhyliaieva.github.io/met_landing)
- [Code](https://github.com/zhyliaieva/met_landing)


## Features
- Responsive Layout (Mobile, Tablet, Desktop)
- Burger Menu for Mobile Devices
- Hero Section with Background Image
- Gallery / Product Section
- Contact Us Form
- Smooth Scrolling Navigation
- Scroll Animations

## Installation / How to run
1. Clone the repository:
```
git clone https://github.com/zhyliaieva/met_landing
```
2. Navigate to the project folder:
```
cd met_landing
```
3. Install dependencies:
```
npm install
```
4. Start the local development server:
```
npm start
```
5. Open http://localhost:8080 in your browser to view the page.
